# Java Programming Notes

A curated collection of **Java Programming Notes, Interview Questions, Coding Programs, Handwritten Notes, Cheat Sheets, and Spring Boot References** in PDF format.

This repository is intended as a single reference collection for learning **Core Java**, revising important concepts, preparing for **Java interviews**, practicing Java programs, and quickly referring to commonly used Java concepts and annotations.

 ## 🗺️ Recommended Java Learning Roadmap

```text
Java Fundamentals
        ↓
Variables, Data Types & Operators
        ↓
Control Flow
(if / else / switch / loops)
        ↓
Methods & Arrays
        ↓
Strings
        ↓
OOP
(Classes → Objects → Encapsulation → Inheritance → Polymorphism → Abstraction)
        ↓
Exception Handling
        ↓
Collections Framework
(List → Set → Map → Queue)
        ↓
Generics
        ↓
File Handling & I/O
        ↓
Multithreading
        ↓
Java 8+ Features
(Lambda → Functional Interfaces → Stream API → Optional)
        ↓
JDBC
        ↓
Java Coding & Problem Solving
        ↓
Core Java Interview Preparation
        ↓
Spring & Spring Boot
        ↓
Spring Boot Annotations
        ↓
Backend Development with Java
```
